# START HERE — what this repository is

A third-party questions-and-constructions collection (no affiliation with Prof. Neil Turok)
on the live problem of **cyclic cosmologies**: what accumulates across cycles, what resets,
and whether any *record* can survive the conformal rescaling between aeons.

## The framing we bring (speculative, tagged [EXTENSION] throughout)

- **Accumulation defines life** (a claim from our group's work, offered here as a question):
  *MIND-ZOE LIFE = INFINITUDES OF NEGENTROPIC ACTIVITY* — negentropic accumulation as the
  definition of life-as-principle (zoe), and identity as an accumulated path of states:
  I = N (Information IS Negentropy).
- The question this repository exists to formalize: **does conformal rescaling preserve any
  invariant of accumulated record?** If a cyclic universe forgets everything at each turn,
  entropy and memory share one budget; if anything carries, what carries, and what is its
  physics? See issue #1.
